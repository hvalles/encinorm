## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tarea concurrente -> `PoolDb.acquire()` | varias tareas compiten por el cupo; el estado `_size`/`_checked_out` cruza el `await` y puede corromperse si la reserva no es atómica |
| `PoolDb` -> adaptador (`Db`) | el pool presta y recupera drivers; el adaptador no sabe si está en uso ni de qué tarea |
| `resolve_db()` -> `Model` | el contextvar pasa a llevar un handle; si no se desenvaina, `Model` recibe un objeto sin `.insert`/`.dialect` |
| caller -> `release()` | una liberación ajena o duplicada puede devolver al pool una conexión que otra tarea aún usa |
