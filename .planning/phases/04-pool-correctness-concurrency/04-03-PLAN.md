## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| llamador -> `release()` | una transacción dejada abierta se confirma o se revierte según la política; una elección equivocada pierde o filtra datos |
| `execute`/`_run` -> driver | el cierre explícito de la transacción ocurre antes de devolver la conexión al pool |
| política de release -> `filterwarnings=["error"]` | un warning mal enganchado (a `in_transaction()`) rompería la suite en MSSQL/Oracle tras cada SELECT |
