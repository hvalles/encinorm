## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app multi-tenant -> caché | la clave de caché cruza el límite de tenant; un hit puede servir datos de otro tenant |
| escritura -> caché | una escritura por clave no-única afecta N filas; la invalidación cruza de la app al backend |
| `CacheBackend` -> app | backend externo (Redis) que puede fallar o devolver una entrada vieja |
