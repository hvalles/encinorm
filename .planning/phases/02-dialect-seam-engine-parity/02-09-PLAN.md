## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| llamador → `list_tables(name=)` | `name` es un VALOR de filtro del llamador; se liga como parámetro y nunca se interpola. |
| core → catálogo del motor | El SQL base de cada motor expone `name` como alias de SELECT; el filtro debe aplicarse sobre una columna real. |
| snapshot `.ambr` → suite | Un `.ambr` regenerado sin revisar puede "bendecir" un cambio de SQL no intencionado. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-48 | Tampering | Interpolar `name` en el SQL del filtro | mitigate | El valor sigue ligado (`params.append(f"%{name}%")` con `{0}` en la plantilla); los tests afirman `page.fields == ["%snap%"]` y que el literal `"snap"` NO aparece en el `sql_template`. No se aplica `check_identifier` a `name` porque es un valor (contiene `%`), no un identificador. |
| T-02-49 | Tampering (Integrity) / Denial of Service | Alias de SELECT referenciado en `WHERE` → `UndefinedColumnError` / `ORA-00911` | mitigate | El filtro se aplica sobre una columna REAL de una tabla derivada (`SELECT * FROM (…) encino_orm_tables WHERE …`), válido en los seis dialectos; cobertura de integración por motor (6 ficheros) y snapshot DB-free del camino filtrado por dialecto. |
| T-02-50 | Tampering | Alias de tabla derivada que empieza por `_` (Oracle `ORA-00911`) | mitigate | El alias elegido es `encino_orm_tables`, sin `_` inicial, coherente con el ya existente `encino_orm_count`; un criterio de aceptación lo comprueba por `grep`. |

| T-02-SC | Tampering | Instalaciones de paquetes | n/a | Este plan no instala ni actualiza dependencias. |
