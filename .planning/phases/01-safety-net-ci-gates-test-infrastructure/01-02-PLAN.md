## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PyPI registry → dev dependency set | Newly added packages are untrusted third-party code that executes in CI and on every contributor's machine |
| `uv.lock` → installed environment | The lockfile is the only thing standing between a floating constraint and an arbitrary resolved version |
| upstream advisory feeds → merge decision | A scan that exits 0 on findings is worse than no scan, because it manufactures confidence |
| `encino_orm/py.typed` → downstream users | The marker promises downstream type checkers that the annotations are meaningful |
