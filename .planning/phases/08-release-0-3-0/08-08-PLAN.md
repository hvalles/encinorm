<objective>
Retirar la API post-hoc `last_id()` de `Db` y `PoolDb` (y el helper centralizado de warning) en la
línea 0.3.0, dejando `execute_insert(qry)` / el retorno de `Model.insert()` como la única vía para
obtener el id (REL-01, parte retirada).

Purpose: el id post-hoc es incorrecto bajo concurrencia (session-scoped en PostgreSQL/MSSQL) y
devuelve el id de OTRA fila sin error. 0.2.7 lo avisó; 0.3.0 lo retira. Aterriza DESPUÉS del tag
`v0.2.7` (08-01) y de la retirada de shims (08-06), y ANTES de promover 0.3.0 (08-03).

Output: `base.py`/`pool.py` sin `last_id`, tests de motores/pool actualizados y
`tests/test_last_id_removed.py` con ausencia + happy path.
</objective>
