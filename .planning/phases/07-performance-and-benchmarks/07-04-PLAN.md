    ```
    import gc, weakref  (si el archivo no los importa ya)
    from encino_orm.model.model import Model, _FIELD_ADAPTERS, _COLUMN_MAPS

    def test_caches_weak_no_retenen_clases_de_modelo():
        # PERF-04 / MEM-02: si _FIELD_ADAPTERS o _COLUMN_MAPS volvieran a ser
        # dicts fuertes, cada clase de modelo definida en un test (o reload)
        # quedaría retenida para siempre.
        assert isinstance(_FIELD_ADAPTERS, weakref.WeakKeyDictionary)
        assert isinstance(_COLUMN_MAPS, weakref.WeakKeyDictionary)

        class Gato(Model):
            _table = "gatos"
            nombre: str

        Gato._column_map()                 # puebla _COLUMN_MAPS[Gato]
        Gato._field_adapter("nombre")      # puebla _FIELD_ADAPTERS[Gato]
        assert Gato in _FIELD_ADAPTERS
        assert Gato in _COLUMN_MAPS

        del Gato
        gc.collect()

        assert not any(k.__name__ == "Gato" for k in _FIELD_ADAPTERS.keys())
        assert not any(k.__name__ == "Gato" for k in _COLUMN_MAPS.keys())
    ```

    Notas de implementación:
    - `_column_map()` y `_field_adapter(...)` son privados de clase; los tests
      del repo ya los usan (convención aceptada).
    - El assert es SOLO sobre los dos dicts del contrato (determinista): pydantic
      puede retener la clase por otros mecanismos internos, pero ese no es el
      contrato de PERF-04. No añadir `weakref.ref(cls)` como gate duro (podría
      volverse flaky si pydantic-core cachea el schema con ref fuerte).
    - `del Gato` dentro de la función + `gc.collect()`; `any(...)` sobre keys:
      si la clase se liberó, `Gato` no está; si el test falla es porque el dict
      la retiene.
    - Verificar que el test no se contamina con clases homónimas de otros tests
      (los tests del repo usan nombres de tabla/modelo propios; `Gato` es único).
