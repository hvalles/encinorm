## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| excepción de driver -> clasificador | el clasificador decide si se reconecta/reintenta; una clasificación errónea cambia el comportamiento de escritura |
| lock -> clasificador de disconnect | un lock clasificado como disconnect se reintentaría fuera de `retry()`, rompiendo el control de deadlocks |
| driver opcional -> importación del adaptador | `pyodbc`/`oracledb` no están en el job `test` de CI; un import duro rompería la colección |
| mensaje localizado del driver -> substring | los mensajes de ODBC vienen localizados (español en este host); el substring no puede ser la fuente primaria |
